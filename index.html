How to install your own copy
  1. Tap Start your own copy. It opens empty, ready for your songs.
  2. iPad or iPhone: in Safari, tap Share (the square with an up arrow; on newer iPads it may be under ⋯), then Add to Home Screen.
    Android: in Chrome, tap ⋮, then Add to Home screen or Install app.
    Computer: in Chrome, click the Install icon in the address bar.
  3. Close the browser and open the app from its new icon. Use the icon from then on; it keeps its own data and works offline.
  4. Tap the ? button inside the app for the full guide.

    How to use the app

    Getting started
    1. Tap the sync button at the top (it says “Sync off” at first) to open Settings. Enter your band name.
    2. Add songs with Add song, or load a CSV from your spreadsheet under Backup.
    3. To keep your devices matched, paste your GitHub access key in Settings. Without a key, everything stays on this device only.
    Install on the iPad
    1. Open the app's address in Safari and tap Share → Add to Home Screen.
    2. Always open it from that icon. The home-screen app keeps its own data, separate from Safari, so set up the sync key from inside it.
    3. After the first open it works with no signal. It updates itself when it opens online.
    Connecting your gear

    1. Drums: iPad to HeadRush (MIDI). The app tells the HeadRush when to start, stop and what tempo to play. No audio goes over this connection.

    Wired (most reliable):

    1. Plug the USB-C MIDI cable into the iPad (or computer).
    2. Plug the cable's OUT plug into the HeadRush's MIDI In. The IN plug can stay loose. If nothing responds, swap plugs; some brands label them the other way around.
    3. Open the app in Web MIDI Browser on the iPad, or Chrome on a computer.
    4. Settings → HeadRush MIDI → Connect MIDI. It should show the cable's name. Pick the MIDI channel the HeadRush listens on (1 unless you changed it).
    5. Test: open a drum song on stage and tap Start. The light on the cable's box should flash.

    Bluetooth (no cable to the HeadRush):

    1. Plug a Bluetooth MIDI adapter into the HeadRush's MIDI In (and power it, if the adapter needs USB power).
    2. Pair it from inside Web MIDI Browser, following the adapter's iPad instructions. Bluetooth MIDI usually doesn't pair from the iPad's own Bluetooth settings.
    3. Settings → HeadRush MIDI → Connect MIDI, then pick the adapter as the MIDI output.
    4. Keep How to set tempo on Tap tempo. MIDI clock can drift over Bluetooth.
    5. Test it at a loud rehearsal before a gig, and keep the wired cable in the gig bag as a backup.

    2. Backing tracks: iPad to the mixer (audio). The track goes to its own channel on the board, not through the HeadRush. No MIDI is needed.

    Track only (no click):

    1. Plug a USB-C audio adapter or small USB-C audio interface into the iPad.
    2. Run its output to a DI box, and the DI to a channel on the mixer.
    3. In Settings → Backing tracks, leave Split output off. The track plays on both sides.
    4. Set the iPad's volume high and steady, and let the sound person set the level at the board.

    Track to the board, click to in-ears:

    1. Use an interface with two outputs, or a stereo cable that splits into two mono plugs (left and right).
    2. Left (the track) → DI → mixer channel for the audience.
    3. Right (the click) → the in-ear monitor mix only. Keep it out of the main speakers.
    4. In Settings → Backing tracks, turn on Split output. Add a click file to each song that needs one.

    Both at once (one iPad port): use an audio interface with a MIDI Out built in, or a USB-C hub. Or use Bluetooth for MIDI so the port is free for audio. A hub with charging pass-through also keeps the iPad charged during the gig.

    Songs
    • Songs is the master list. Tap a song to edit it. Changes show up in every setlist that uses it.
    • Tuning drives the retune warnings. Write it like E, Eb, Drop D, Drop Db or Capo 2.
    • Charts has three pages per song. Fill in any of them:
      Tab plays in time with the song's BPM. Put | between bars, since the app times each line by counting its bars. Add x2 (or x3, x4) after a line that repeats. Any plain line shows as a small lyric cue, so put lyrics right above the staff they go with. Set Beats per bar if the song isn't in 4.
      Lyrics: paste lyrics, or a chord chart with chords on the line above the words. Turn off Show chords on stage for lyrics-only songs.
      Sheet is a page that doesn't scroll, for riffs, lyrics or reminders.
      Add bass staff drops in four empty bars to type frets into. Lines like [Chorus] become section labels on every page.
    • Opens to picks which page shows first on stage. Automatic opens Lyrics if there are any, then Tab, then Sheet.
    • Notes show under the song title on stage (e.g. “capo off, Brian starts”).
    Setlists
    • Tap Setlists → New setlist, name it and set the date.
    • Add songs lets you check songs off the master list.
    • Reorder with ▲ ▼, remove with ×. Group by tuning sorts the set so you retune as little as possible (Undo is in the message that pops up).
    • Retune lines between songs, and the retune count at the top, update as you go.
    • Duplicate copies a setlist for the next gig.
    On stage
    • Tap ▶ Play set, or tap any song in a setlist, to open it full screen.
    • If a song has more than one page, switch between Tab, Lyrics and Sheet at the top.
    • Lyrics: Scroll starts auto-scroll. − / + next to it change the speed. Tap the lyrics to pause.
    • Tab: Play counts in, then scrolls in time. The line you're on stays a third of the way down the screen, and a cursor moves through each bar. − / + change the BPM. Tap the tab to pause, drag to any spot, and Play picks up from the bar at the cursor. With drums, Start runs the drums and the tab together. A page-turner jumps to the next or previous line while it's playing.
    • Sheet stays put. Use A− / A+ to size it. If the sheet has a line with just ===, it splits into screens: one flick (or a page-turner press) moves a whole screen.
    • A− / A+ change the text size. Speed and size are remembered for each song.
    • Next › shows what's next and warns you if you need to retune.
    • A Bluetooth page-turner works too. Up/down scrolls, left/right changes song.
    Drums (HeadRush)
    1. On the HeadRush, set up a drum preset you like. For a plain kick, mute Snares, Cymbals and Toms.
    2. Connect the MIDI cable to the HeadRush's MIDI In. Open the app in Chrome on a computer, or in the Web MIDI Browser app on the iPad. Safari can't send MIDI.
    3. In Settings → HeadRush MIDI, tap Connect MIDI.
    4. In a song, turn on Drums and set the BPM (use Tap to tap it in while the record plays). Add a Rig # if the song should load a rig.
    5. On stage: Start counts in, then starts the drums. Fill, End (outro) and Stop work right away. Moving to the next song stops the drums.
    6. − / + change the tempo live. From a setlist, the change is saved for that gig only. Use “Make this the song's BPM” to keep it.
    Backing tracks
    1. In a song, under Backing track, tap Choose track… (MP3, M4A or WAV). Add an optional click file for in-ears.
    2. Audio stays on the device you added it on. Add the files on each iPad that plays them.
    3. On stage: Start plays the track and scrolls the lyrics so they end with the song. Fade brings it down over 4 seconds. Stop cuts it.
    4. For in-ears, turn on Split output in Settings: track on the left side to the board, click on the right side to the monitor mix.
    Bands
    • Settings → Bands → type a name → Add band. Each band has its own songs and setlists. A new band syncs to its own file in the same data repo with the same key, so there is nothing else to set up.
    • Switch bands with the menu at the top.
    • To share a band between people, use one private data repo for that band and give each person access. Each person enters their own key.
    Sync and backup
    • The sync button shows the status. “Synced just now” means this device matches your data repo.
    • Before a gig: open the app at home and check that it says Synced. Then it's fine with no signal.
    • Changes made offline sync the next time the app is online. If the same song is edited on two devices offline, the latest edit wins.
    • Backup → Save backup file saves everything except audio files. Load restores it or moves it to another device.
